Lab Task 2: Debugging Answers

  1. What did the Console say? What does it mean?
    The Console may show "Identifier has already been declared" if copying the script declares the same const or let variable twice. The exact error depends on the original code.
  2. The Network tab was fine. What does that tell you?
    If d3.v7.min.js and penguins.csv both have status 200, the files loaded successfully, so the problem is likely in the JavaScript code rather than file loading.
  3. What did Elements show that the Console did not?
    Elements lets us inspect each SVG and see whether it contains the expected three rect elements representing the bars in each chart.
  4. What did you change to fix it?
    I used separate variable names and unique SVG IDs for both charts so that each chart is drawn in the correct SVG without duplicate variable declarations.
